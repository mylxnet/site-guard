## 5. 已知限制（测试视角）

| 限制 | 影响 | 备注 |

### 7.1 API 级验收（0.6.0，无界面也能验）

1. `npm start`，浏览器完成初始化；用 curl 或 REST 客户端保存 Cookie。
2. 建站点（`POST /api/sites`）→ 建页面（`POST /api/sites/:id/pages`，带 `mustContain`）。
3. `POST /api/pages/:id/run`：应返回 `verdict=normal` 且 `baselineId>0`；`GET /api/pages/:id/detail` 能看到基线。
4. 修改该页面内容，再跑一次：`changed=true`；`GET /api/pages/:id/diff` 能看到新增/删除行。
5. `POST /api/pages/:id/accept` 后再取差异，应为空。
6. 把页面地址改成返回 502 的地址再跑：`verdict=bad`，`accept` 返回 409。
7. `GET /api/overview` 的统计与页面状态一致。
8. `PUT /api/settings` 填 SMTP（QQ/163 用授权码）→ `POST /api/settings/test-mail` 收到测试邮件。
9. 改页面内容后 `POST /api/sites/:id/run`，等批次 `done`：应收到一封汇总邮件，`GET /api/events?type=changed` 里该事件 `notified=true`。
10. 6 小时内再改一次并重跑：不应收到第二封；事件仍存在，`notified=false`。
